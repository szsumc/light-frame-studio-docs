# Light Frame Studio Docs

Documentation website for Light Frame Studio, a Windows desktop tool for batch-generating framed photos with EXIF details, branding, and color sampling.

## Contents

- Multilingual product documentation in Chinese, Japanese, and English
- Download link for the latest Windows release
- Template examples and detailed release notes
